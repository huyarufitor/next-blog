前端岗位的边界已经从“把页面写出来”扩展到浏览器运行时、复杂应用架构、工程效率、服务端协作、AI 产品和线上运维。一份只包含 JavaScript 闭包与 Vue 生命周期的题库，很难覆盖今天的真实工作。

这份题库共 240 题，按知识领域而不是简历关键词组织。每题都给出简明参考答案、考察重点和继续追问，适合面试官抽题，也适合候选人建立知识地图。

> 参考答案用于校准方向，不是唯一标准。场景题更应关注候选人的约束识别、取舍过程与验证方法。

## 如何使用这份题库

- 初级岗位：基础模块为主，搭配 2 至 3 道项目场景题。
- 中级岗位：基础抽查，重点考框架、性能、工程化和故障定位。
- 高级岗位：减少定义题，重点考架构、稳定性、全栈边界和技术决策。
- AI 前端岗位：除常规前端能力外，增加流式交互、模型输出、安全和可观测性。
- 每次面试建议选择 12 至 18 题，不要把题库变成流水线考试。

## 一、HTML、CSS 与 Web 平台基础

### 1. HTML 语义化有什么价值？

**参考答案**：使用与内容含义匹配的元素，能改善可访问性、SEO、默认交互和代码可维护性。
**考察重点**：是否理解语义不等于标签外观。
**继续追问**：`main`、`article`、`section` 和 `nav` 如何选择？

### 2. DOCTYPE 的作用是什么？

**参考答案**：声明文档类型，让浏览器按标准模式解析页面，避免进入怪异模式。
**考察重点**：浏览器兼容基础。
**继续追问**：标准模式与怪异模式会影响哪些布局行为？

### 3. script 的 async 与 defer 有什么区别？

**参考答案**：两者都并行下载；`async` 下载后立即执行且顺序不确定，`defer` 在解析完成后按文档顺序执行。
**考察重点**：资源加载与 HTML 解析关系。
**继续追问**：模块脚本的默认行为是什么？

### 4. DOMContentLoaded 与 load 有什么区别？

**参考答案**：前者在 DOM 解析完成后触发，后者等待页面依赖资源基本加载完成。
**考察重点**：页面生命周期。
**继续追问**：延迟脚本会如何影响 DOMContentLoaded？

### 5. 浏览器如何处理未知 HTML 标签？

**参考答案**：HTML 解析器通常会创建通用元素节点，但其语义、默认样式与行为并不存在。
**考察重点**：HTML 容错与自定义元素区别。
**继续追问**：Web Components 如何注册自定义元素？

### 6. iframe 有哪些常见问题？

**参考答案**：隔离性较强，但会带来通信、性能、SEO、可访问性、路由和安全策略问题。
**考察重点**：嵌入式架构边界。
**继续追问**：sandbox、CSP 和 postMessage 如何配合？

### 7. 什么是渐进增强？

**参考答案**：先保证基础内容和核心能力可用，再根据浏览器能力增加更丰富的交互。
**考察重点**：兼容性与用户可达性。
**继续追问**：如何使用特性检测而不是浏览器判断？

### 8. 可访问性中的键盘操作需要关注什么？

**参考答案**：焦点顺序、可见焦点、语义控件、快捷键冲突、弹窗焦点圈定和关闭后的焦点恢复。
**考察重点**：是否做过真实无障碍交互。
**继续追问**：为什么不应随意给普通 div 添加 tabindex？

### 9. ARIA 的使用原则是什么？

**参考答案**：优先使用原生语义元素，ARIA 只补充缺失语义，不会自动增加行为。
**考察重点**：语义与交互实现。
**继续追问**：自定义下拉框需要哪些角色和状态？

### 10. 图片的 alt 应该怎么写？

**参考答案**：描述图片在当前上下文中的信息价值；纯装饰图片使用空 alt，避免重复周边文字。
**考察重点**：可访问性细节。
**继续追问**：复杂图表如何提供替代信息？

### 11. CSS 盒模型包含哪些部分？

**参考答案**：内容、内边距、边框和外边距；`box-sizing` 决定声明尺寸是否包含内边距与边框。
**考察重点**：布局基本功。
**继续追问**：为什么项目常全局使用 border-box？

### 12. 什么是 BFC？

**参考答案**：块级格式化上下文是独立布局环境，会影响浮动参与、外边距折叠和高度计算。
**考察重点**：能否用布局规则解释现象。
**继续追问**：哪些方式会创建 BFC，各有什么副作用？

### 13. margin 为什么会折叠？

**参考答案**：普通文档流中相邻块级垂直外边距可能合并，这是块格式化规则的一部分。
**考察重点**：CSS 规则而非经验补丁。
**继续追问**：父子元素外边距折叠如何避免？

### 14. position 的不同取值如何确定包含块？

**参考答案**：static 按普通流；relative 相对自身原位置；absolute 通常相对最近定位祖先；fixed 通常相对视口；sticky 在滚动容器内切换行为。
**考察重点**：定位上下文。
**继续追问**：transform 为什么可能改变 fixed 的参照？

### 15. z-index 为什么有时不生效？

**参考答案**：元素可能不在同一层叠上下文，子元素的层级无法越过父级上下文比较。
**考察重点**：层叠上下文。
**继续追问**：哪些属性会创建新的层叠上下文？

### 16. Flex 布局中 flex: 1 通常代表什么？

**参考答案**：常见实现等价于增长为 1、收缩为 1、基础尺寸为 0，但应结合规范与浏览器计算值判断。
**考察重点**：剩余空间分配。
**继续追问**：为什么 flex 子项会因 min-width 导致溢出？

### 17. Grid 与 Flex 应该如何选择？

**参考答案**：Flex 更适合一维排列和内容驱动布局，Grid 更适合同时控制行列的二维布局。
**考察重点**：工具选择而非站队。
**继续追问**：repeat、minmax 和 auto-fit 如何组合响应式网格？

### 18. 如何实现稳定的响应式设计？

**参考答案**：以内容断点、流式尺寸、弹性布局和容器约束为主，必要时结合媒体与容器查询。
**考察重点**：是否依赖固定设备宽度。
**继续追问**：容器查询解决了媒体查询的什么局限？

### 19. rem、em、vw 和 px 如何选择？

**参考答案**：px 适合稳定像素边界；rem 关联根字号；em 关联当前上下文；视口单位适合与视口相关尺寸，但需注意动态视口。
**考察重点**：单位语义和可访问性。
**继续追问**：移动端地址栏会如何影响 vh？

### 20. CSS 变量和预处理器变量有什么区别？

**参考答案**：CSS 变量存在于运行时、参与继承并可动态修改；预处理器变量在构建时替换。
**考察重点**：运行时主题能力。
**继续追问**：如何用 CSS 变量实现多主题和组件级覆盖？

## 二、JavaScript 与 TypeScript

### 21. JavaScript 有哪些原始类型？

**参考答案**：undefined、null、boolean、number、bigint、string 和 symbol；对象属于引用类型。
**考察重点**：语言类型系统基础。
**继续追问**：typeof null 为什么返回 object？

### 22. Object.is 与 === 有什么区别？

**参考答案**：主要差异是 Object.is 认为 NaN 等于自身，并区分正零和负零。
**考察重点**：相等语义。
**继续追问**：React 状态比较为何常使用 Object.is 语义？

### 23. 什么是隐式类型转换？

**参考答案**：运算或比较时，规范会按抽象操作把值转换成目标类型，不同操作符规则不同。
**考察重点**：是否理解规则而非背怪例子。
**继续追问**：加号为什么同时承担数值加法和字符串拼接？

### 24. 如何可靠判断数组？

**参考答案**：使用 `Array.isArray`，它能跨 realm 工作，比 instanceof 更可靠。
**考察重点**：运行环境边界。
**继续追问**：iframe 为什么会让 instanceof 失效？

### 25. 深拷贝有哪些限制？

**参考答案**：需要处理循环引用、原型、Date、Map、Set、TypedArray、函数和不可克隆对象；没有适合所有对象的通用语义。
**考察重点**：反对 JSON 序列化万能论。
**继续追问**：structuredClone 能处理和不能处理什么？

### 26. 原型链是如何工作的？

**参考答案**：对象属性查找会沿内部原型链向上，直到找到属性或到达 null。
**考察重点**：对象模型。
**继续追问**：class 语法与原型继承是什么关系？

### 27. new 操作符做了什么？

**参考答案**：创建以构造函数 prototype 为原型的对象，以该对象作为 this 调用函数，并按返回值规则返回实例。
**考察重点**：构造调用机制。
**继续追问**：构造函数显式返回对象会怎样？

### 28. this 的绑定规则有哪些？

**参考答案**：根据调用位置分为默认、隐式、显式和 new 绑定，箭头函数则词法捕获外层 this。
**考察重点**：调用方式而非定义位置。
**继续追问**：bind 后再 new 会发生什么？

### 29. call、apply 与 bind 的区别是什么？

**参考答案**：call 和 apply 立即调用，参数形式不同；bind 返回绑定了 this 与部分参数的新函数。
**考察重点**：函数调用控制。
**继续追问**：如何实现一个考虑 new 的 bind？

### 30. 什么是闭包？

**参考答案**：函数与其词法环境的组合，使函数在外层执行结束后仍可访问相关变量。
**考察重点**：词法作用域和实际用途。
**继续追问**：闭包什么时候会造成不必要的内存保留？

### 31. var、let 与 const 有什么区别？

**参考答案**：var 是函数作用域并存在提升行为；let 和 const 是块作用域且有暂时性死区；const 禁止重新绑定而非冻结对象。
**考察重点**：作用域和绑定。
**继续追问**：循环中的 let 为什么能为回调保留不同值？

### 32. 什么是执行上下文？

**参考答案**：它描述代码执行时的词法环境、变量环境、this 等状态，并通过调用栈管理函数执行。
**考察重点**：作用域与调用栈关系。
**继续追问**：递归过深为什么会栈溢出？

### 33. 事件循环如何协调任务？

**参考答案**：同步代码运行在调用栈；任务队列按事件循环调度，微任务通常在当前任务结束后、渲染机会前清空。
**考察重点**：异步执行顺序。
**继续追问**：浏览器和 Node.js 的事件循环有哪些差异？

### 34. Promise 的状态和链式调用原理是什么？

**参考答案**：Promise 只能从 pending 转为 fulfilled 或 rejected；then 返回新 Promise，并按回调结果解析其状态。
**考察重点**：Promise 解析过程。
**继续追问**：返回 thenable、抛错和返回普通值分别怎样传播？

### 35. async 与 await 的本质是什么？

**参考答案**：async 函数总返回 Promise；await 暂停当前异步函数，并把后续逻辑安排到 Promise 结算后的微任务。
**考察重点**：语法糖后的异步模型。
**继续追问**：串行 await 如何改成受控并发？

### 36. Promise.all 与 allSettled 如何选择？

**参考答案**：all 适合任一失败就整体失败；allSettled 适合收集每项结果并分别处理。
**考察重点**：失败语义。
**继续追问**：如何实现限制并发数的任务池？

### 37. 如何取消异步操作？

**参考答案**：Promise 本身不可取消，通常通过 AbortController 或业务取消标记让底层操作停止或忽略结果。
**考察重点**：取消需要协作。
**继续追问**：组件卸载时如何取消 fetch 和后续状态更新？

### 38. 防抖与节流有什么区别？

**参考答案**：防抖在停止触发一段时间后执行；节流限制单位时间内的执行频率。
**考察重点**：场景选择。
**继续追问**：leading、trailing 和 maxWait 如何设计？

### 39. 函数柯里化有什么用途？

**参考答案**：把多参数函数转为逐步接收参数的函数，便于参数复用、组合和延迟执行。
**考察重点**：函数式抽象。
**继续追问**：柯里化与偏函数有什么差异？

### 40. Map 与普通对象如何选择？

**参考答案**：Map 支持任意键、明确大小和稳定迭代语义；对象更适合固定字段的数据记录。
**考察重点**：数据结构选择。
**继续追问**：WeakMap 的键为什么必须是对象？

### 41. Set 的典型应用是什么？

**参考答案**：唯一值集合、成员判断、集合运算和去重，但对象去重仍依赖引用身份。
**考察重点**：集合语义。
**继续追问**：如何按对象某个字段去重并保留最后一项？

### 42. Symbol 解决了什么问题？

**参考答案**：提供唯一属性键并支持内置协议，如迭代器和类型标签，减少属性命名冲突。
**考察重点**：语言扩展协议。
**继续追问**：全局 Symbol 注册表有什么用途？

### 43. 迭代器与可迭代对象是什么关系？

**参考答案**：可迭代对象通过 Symbol.iterator 返回迭代器，迭代器的 next 依次返回 value 与 done。
**考察重点**：for of 的协议基础。
**继续追问**：如何让自定义数据结构支持 for of？

### 44. Generator 适合解决什么问题？

**参考答案**：它可暂停和恢复执行，适合实现迭代器、惰性序列和可控流程。
**考察重点**：生成器控制流。
**继续追问**：yield star 的作用是什么？

### 45. Proxy 与 defineProperty 的区别是什么？

**参考答案**：Proxy 代理对象级操作并覆盖更多内部方法；defineProperty 主要定义单个属性描述符。
**考察重点**：元编程能力。
**继续追问**：Proxy 有哪些不可违反的不变量？

### 46. 属性描述符有哪些字段？

**参考答案**：数据属性包含 value、writable；访问器属性包含 get、set；两者共有 enumerable 与 configurable。
**考察重点**：对象属性模型。
**继续追问**：冻结对象分别修改了哪些描述符？

### 47. ES Module 与 CommonJS 的主要区别是什么？

**参考答案**：ESM 具有静态结构和实时绑定，利于分析；CommonJS 通常在运行时同步加载并导出对象。
**考察重点**：模块语义。
**继续追问**：循环依赖在两种模块中表现有何不同？

### 48. Tree Shaking 为什么依赖 ESM？

**参考答案**：静态 import/export 使构建工具能在不执行代码的情况下分析依赖和未使用导出。
**考察重点**：静态分析条件。
**继续追问**：sideEffects 配置错误会造成什么问题？

### 49. 垃圾回收通常基于什么原则？

**参考答案**：现代引擎主要判断对象是否从根集合可达，并结合分代、标记清除等策略回收内存。
**考察重点**：可达性而非引用计数简化模型。
**继续追问**：闭包、事件监听和缓存如何造成内存泄漏？

### 50. 如何定位前端内存泄漏？

**参考答案**：稳定复现操作，观察堆趋势，比较 Heap Snapshot，检查 Detached DOM、持续增长集合和未释放监听。
**考察重点**：工具化排查。
**继续追问**：为什么单次堆大小上涨不能证明泄漏？

### 51. TypeScript 的 any 与 unknown 有什么区别？

**参考答案**：any 基本关闭类型检查；unknown 接受任意值，但使用前必须缩小类型。
**考察重点**：安全边界。
**继续追问**：catch 变量为什么适合使用 unknown？

### 52. interface 与 type 如何选择？

**参考答案**：两者都能描述对象；interface 支持声明合并和面向对象扩展，type 更适合联合、交叉与类型运算。
**考察重点**：避免绝对化结论。
**继续追问**：库的公共类型为什么常偏向 interface？

### 53. 联合类型与交叉类型有什么区别？

**参考答案**：联合表示值满足多个类型之一；交叉表示同时满足多个类型的约束。
**考察重点**：集合视角理解类型。
**继续追问**：对象交叉出现冲突字段时会怎样？

### 54. 什么是类型缩小？

**参考答案**：通过 typeof、in、instanceof、判别字段或自定义守卫，让编译器确定更具体的类型。
**考察重点**：控制流分析。
**继续追问**：如何编写返回 type predicate 的守卫？

### 55. 泛型解决了什么问题？

**参考答案**：在保留类型关系的前提下复用实现，避免用 any 丢失输入与输出之间的约束。
**考察重点**：类型关系建模。
**继续追问**：泛型约束和默认参数如何使用？

### 56. keyof 与 typeof 在类型位置有什么用途？

**参考答案**：keyof 获取对象类型的键联合；类型位置的 typeof 获取值的静态类型。
**考察重点**：从值派生类型。
**继续追问**：如何让配置对象既校验又保留字面量类型？

### 57. 映射类型是什么？

**参考答案**：它遍历键集合并为每个键生成属性，可配合修饰符和键重映射构造新类型。

**考察重点**：发布风险控制。
**继续追问**：数据库变更如何保持两个版本兼容？

### 232. 前端灰度可以按什么维度实施？

**参考答案**：用户、租户、地区、设备、版本、比例或功能开关，需保证分组稳定并可快速停止。
**考察重点**：灰度与业务身份结合。
**继续追问**：静态 CDN 资源如何支持多版本灰度？

### 233. 回滚为什么不只是重新部署旧代码？

**参考答案**：数据库、缓存、接口契约、客户端资源和异步任务可能已变化，需要向前兼容、数据恢复或功能开关。
**考察重点**：回滚是系统能力。
**继续追问**：如何在上线前验证回滚方案？

### 234. 告警应该如何避免噪声？

**参考答案**：围绕用户影响和可行动性设阈值、持续时间、分组和抑制，区分症状告警与原因诊断。
**考察重点**：告警必须可操作。
**继续追问**：错误率突增和低流量服务如何设置告警？

### 235. 线上事故处理的基本顺序是什么？

**参考答案**：确认影响，优先止损和恢复，保留证据并沟通状态，随后定位修复，最后做无责复盘和行动跟踪。
**考察重点**：恢复优先于追责和完美根因。
**继续追问**：事故指挥者与排查人员如何分工？

## 十一、综合场景设计题

### 236. 如何设计一个稳定的登录系统前端？

**参考答案**：处理认证状态恢复、过期刷新、并发刷新、权限路由、跨标签同步、安全存储、异常降级和可观测性。
**考察重点**：登录是状态机和安全链路。
**继续追问**：刷新令牌失效时多个并发请求如何收敛？

### 237. 如何设计一个大文件上传系统？

**参考答案**：文件识别、切片、并发和暂停、断点记录、失败重试、服务端幂等合并、完整性校验与安全扫描缺一不可。
**考察重点**：端到端可靠性。
**继续追问**：网络切换与浏览器重启后如何续传？

### 238. 如何设计一个低代码表单平台？

**参考答案**：定义版本化 Schema、物料协议、编辑与渲染分层、联动表达式、数据源、权限、预览发布和迁移能力。
**考察重点**：扩展性、安全和版本治理。
**继续追问**：如何实现撤销重做和多人编辑？

### 239. 如何设计一个 AI 工作流画布？

**参考答案**：需要节点与边模型、合法性校验、变量引用、撤销重做、布局、流式执行状态、断点调试和大画布性能。
**考察重点**：编辑器状态与运行状态分离。
**继续追问**：如何检测环和无效变量依赖？

### 240. 如何设计一个从监控到回滚的前端稳定性体系？

**参考答案**：统一版本标识，采集错误、性能和业务指标，关联发布与链路，设置灰度门槛、告警、功能开关和自动或人工回滚流程。
**考察重点**：监控必须连接发布决策。
**继续追问**：如何证明一次回滚真正恢复了用户体验？

## 按岗位快速组卷

### 初级前端

从 1 至 90 题中选择 10 题，重点覆盖 HTML/CSS、JavaScript、浏览器和网络；再从框架模块选择 3 题，从场景题选择 1 题。

### 中级前端

基础模块抽查 5 题，框架与性能选择 6 题，工程化选择 4 题，最后使用 1 至 2 道综合场景题深挖项目能力。

### 高级前端

减少定义题，从性能、工程化、架构、全栈和稳定性各选 2 至 3 题。要求候选人主动提出约束、替代方案、验证指标和失败处理。

### AI 前端

先验证常规前端基础，再从实时通信、安全、AI 应用和运维模块选择至少 8 题。AI 产品仍然是软件系统，不能绕过工程质量与安全。

## 最后

完整题库的价值不是让面试官问得更多，而是让每个问题都有明确目的。一次面试选择少量题目问深，比按顺序刷完几十道定义题更能判断候选人的真实能力。

对候选人而言，也不必背下 240 个答案。更有效的方法是建立知识之间的联系，并能用自己的项目解释原理、取舍和结果。
