## 三种内容放在哪里

经过整理、适合持续传播的长文放在 `content/posts`。公开的学习记录放在
`content/notes`，它们会出现在知识库、站内搜索和 Sitemap 中。

不适合公开或仍包含敏感信息的材料放在 `content/notes-local`。这个目录不会被 Git
跟踪，生产构建也不会读取其中内容。

## 迁移前先审核

旧 VuePress 目录可能包含完整项目、第三方 README 和转载材料。迁移工具只处理清单中
明确列出的单个 Markdown 文件，不会递归导入整个旧目录。
