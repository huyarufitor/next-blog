# 全栈前端面试题库文章设计

## 目标

生成一篇面向面试官和候选人的完整前端题库文章，覆盖基础、进阶、高级、工程化、全栈、AI 应用和运维。它与已有的“从简历追问真实水平”文章互补：上一篇解决怎么问深，这一篇解决不同岗位和领域可以问什么。

## 内容规模

- 总题量不少于 200 道。
- 每题包含问题、参考答案、考察重点和可继续追问。
- 答案以准确、可检索的短答案为主，复杂场景给出判断框架而非唯一结论。
- 使用连续编号和模块目录，便于面试官按领域抽题。

## 模块划分

1. HTML、CSS 与 Web 平台基础。
2. JavaScript 与 TypeScript。
3. 浏览器、网络与安全。
4. Vue、React 与状态管理。
5. 性能、跨端、可视化和实时通信。
6. 前端工程化、测试、Monorepo 与监控。
7. 高级架构、低代码和团队治理。
8. Node.js、数据库、缓存与 BFF。
9. AI 场景下的前端应用和 AI Coding。
10. Linux、Nginx、Docker、CI/CD、灰度和故障处理。
11. 场景设计题与岗位组卷建议。

## 发布方式

文章写入 `content/posts`，分类为“技术实践”。初始使用 `draft: true`，待人工检查题目口径与篇幅后再公开。题库不包含候选人个人信息，也不直接复用上一篇的简历追问格式。
