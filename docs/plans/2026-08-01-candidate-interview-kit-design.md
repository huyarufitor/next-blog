# 前端候选人面试资料包设计

## 目标

为 Vue 2/Vue 3 管理后台、少量客户端 H5 运营活动页岗位建立一套可复用的面试资料，并针对五名候选人生成约 60 分钟的差异化面试单。

## 存储与隐私

- 所有正式材料存放在 `content/notes-local/interviews/`，仅供本地使用。
- 该目录已被 `.gitignore` 排除，不参与 Git 提交和线上构建。
- 候选人面试单只保留姓名、年限、面试形式和技术经历，不记录电话、邮箱、年龄、照片等无关个人信息。

## 资料结构

1. `README.md`：入口、使用方法和五场面试索引。
2. `frontend-interview-question-bank.md`：公共题库，按岗位能力域组织，每题包含主问题、考察点、参考答案、追问和判断信号。
3. `interview-scorecard.md`：统一评分表和录用建议规则。
4. `candidates/*.md`：五份 60 分钟面试单，包含时间安排、必问题、简历证据链追问、风险点与面试记录区。

## 面试策略

- 公共基线重点考察 JavaScript、Vue、管理后台、H5/JSBridge、工程化与故障处理。
- Node.js、AI 应用和 Vibe Coding 属于加分能力，不替代前端核心能力。
- 4 年候选人侧重独立交付、问题定位和技术基本盘；8 年候选人增加架构取舍、质量体系、团队影响和结果可信度。
- 线上面试强化代码阅读式口述、时序推演和证据细节；线下面试强化白板架构、状态机和故障排查推演，不安排现场编码。

## 质量标准

- 题目贴近实际工作，不按名词堆砌八股题。
- 相同知识点只保留一个主问题，通过追问调节难度。
- 每份候选人面试单控制在 60 分钟内，并明确可跳过问题。
- 评分维度统一，使五名候选人的结论可以横向比较。
