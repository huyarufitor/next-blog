# Sub2API 本地部署教程实施计划

**目标：** 将已搭建的 Sub2API 整理为公开中文教程，使用真实截图和独立封面，在首页近期文章首位展示。

**方案：** 复用现有 MDX 文章与日期排序机制，选择 `content/posts`；无需增加首页置顶功能或生产依赖。另一个可选方案是增加永久置顶字段，但本次只要求新文章优先展示，暂不扩大范围。

**技术：** Next.js、MDX、ImageResponse、现有 Vitest 测试；验证使用 Node.js 22 与 npm。

## 来源与事实边界

- 用户确认使用 Sub2API；本机部署说明、Compose 模板、中文界面文案与网关路由作为步骤依据。
- 只读检查确认 Sub2API、PostgreSQL、Redis 容器 healthy，应用映射为 `127.0.0.1:8888 -> 8080`。
- 实际浏览器可访问登录页；未读取 `.env`、数据库、Token 文件或认证日志，未进行上游模型调用。
- OpenAI Responses 请求格式已核对官方文档；第三方网关的授权能力以本地版本为准，不表述为官方支持。
- 正文原创整理并引用上游来源；不复制第三方赞助宣传、源码或凭据。不引入个人目录路径、账号邮箱、内部 URL 或账单数据。
