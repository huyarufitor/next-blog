# 可折叠文章目录设计

## 目标

让长文章的侧边目录可以在视口内独立滚动，并支持整体折叠和按二级标题折叠三级子标题，解决目录过长时无法浏览全部内容的问题。

## 交互设计

- 整体目录使用原生 `details` 和 `summary`，默认展开。
- 每个包含三级标题的二级标题形成独立 `details` 分组，默认收起。
- 二级标题文字负责跳转正文，独立的 summary 控件负责展开或收起子标题。
- 没有三级子标题的二级标题直接显示为链接。
- 展开的目录内容限制为视口可用高度，并启用纵向滚动和 overscroll containment。

## 技术设计

`PostToc` 保持服务端组件，不引入 React 状态或新依赖。组件先把扁平 `TocEntry[]` 转换成二级标题分组，再渲染语义化原生控件。共享组件的变化会同时覆盖文章、知识库与访谈阅读页。

## 验证

新增组件测试覆盖空目录、带子标题分组、无子标题链接、原生整体折叠和滚动容器样式。完成后运行 lint、测试、类型检查和生产构建。
